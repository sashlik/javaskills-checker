Приложение для проверки выполнения всех условий задания

При старте поднимает тестовый SOAP веб-сервис, а также тестовый REST API. В который будет обращаться приложение участника по условию задания.
Приложение должно запускаться после того как приложение участника уже запущено и готово к вызовам по API
После поднятия сервисов проверяющее приложение начинает вызывать API участника в разных вариантах и проверять, что условия задания выполняются. 
После проведения всех тестов, приложение останавливается, гася также тестовые веб-сервис и рест сервис.

Для тестирования API приложения участника, необходимо прописать переменную окружения с URL тестируемого приложения api.endpoint, например api.endpoint=http://localhost:8091

В тестируемом приложении, в свою очередь, нужно указать URL поднимаемого веб-сервиса и рест сервиса. Например если данное приложение поднимается на localhost и пору 8090, то в тестируемом приложении нужно указать следующие ENV переменные: 

ws.endpoint=http://localhost:8090/ws
rs.endpoint=http://localhost:8090
